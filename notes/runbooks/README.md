# 执行手册

需要租机器、跑实验的 issue，动手前先在这里写一份可执行方案：**每一步敲什么命令、产出什么、卡住了怎么办**。

和另外两条线的区别：

| 线 | 时机 | 性质 |
| --- | --- | --- |
| [runbooks/](.) | **事前** | 开机照着敲的操作手册 |
| [prs/](../prs/README.md) | **事后** | 这个 PR 的前因后果留档 |
| [onboarding/](../onboarding/README.md) | 入门 | 环境、流程、怎么找任务 |
